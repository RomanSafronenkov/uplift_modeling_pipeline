# Uplift modeling pipeline

Репозиторий с пайплайном обучения uplift моделей на базе мета-лернеров

## Установка

Для работы необходим Python 3.11+
Если запуск происходит не на Windows:

```bash
source ./install.sh
```

Если запуск происходит локально, необходимо для работы pyspark установить Java.

MacOS:
```bash
brew install openjdk@11
sudo ln -sfn /opt/homebrew/opt/openjdk@11/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-11.jdk
```

## Содержание

- ./notebooks - директория с ноутбуками, последовательный запуск которых и есть пайплайн
- ./src - директория со вспомогательным кодом
- ./config.yaml - пример конфига для пайплайна, перед запуском необходимо заполнить

Основная директория **./notebooks** содержит:
- 1_data_manipulation - ноутбук с подготовкой данных, необхдимо менять под свои данные, генерировать признаки, заполнять пропуски, формировать выборки
- 2_feature_selection - ноутбук с отбором признаков
- 3_model_choosing - ноутбук с выбором архитектуры решения (на текущий момент из S, T, X learner-ов)
- 4_optimization - оптимизация гиперпараметров выбранной архитектуры
- 5_fit_and_evaluate_model - обучение модели и проверка метрик на выборках

## Заполнение конфига

[Конфигурационный файл](./config.yaml) содержит:
- general - основной раздел, название эксперимента, включение/выключение основных этапов пайплайна
- dataset - раздел с неймингом основных колонок и долей датасета на OOS
- feature_selection - заполнение пропусков, удаление столбцов
- optimization - число optuna trials, метрика оптимизации

## Обучение модели

Для обучения модели нужно пройти по порядку по всем [ноутбукам](./notebooks).
В результате создается директория ./artifacts:

```
artifacts/
└── <EXPERIMENT_NAME>/          # Директория конкретного эксперимента
    ├── config.yaml             # Конфигурация запуска эксперимента
    ├── status.json             # Текущий статус и метаданные эксперимента
    │
    ├── feature_selection/      # Результаты отбора признаков
    ├── img/                    # Графики и визуализации
    ├── log/                    # Логи выполнения
    ├── optimize/               # Результаты оптимизации гиперпараметров
    └── choose_model/           # Результаты выбора финальной модели
```
